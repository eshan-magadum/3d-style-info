# Choosing a 3D short profile

Use these reference clips as separate production modes rather than one blended average.

| Story goal | Primary reference | Borrow from | Avoid |
|---|---|---|---|
| Emotional true story / recovery | 01 Tattoo | 05's object-led timeline and 02's atmosphere | Unmotivated explosions or excessive injury detail |
| Rescue / danger / survival | 02 Leopard | 01's clear evidence inserts | Crushing shadows or action that hides contact |
| Comedy anecdote | 03 Classroom | 04's clean concept props | Dark thriller lighting and over-realistic distress |
| Science / psychology demonstration | 04 Dream test | 05's visualized text and time/space transitions | Random text changes or surreal imagery without a spoken reason |
| Historical experiment / tragedy | 05 Dolphin | 01's emotional payoff and 04's concept visualization | Treating uncertain reenactment details as verified fact |

## Recommended default for a new “3D info shorts” kit

Use **cinematic narrated 3D story** as the project default: recognizable real-world materials, stylized-but-readable faces, story-specific lighting, textured props, steady camera movement, and visual evidence in each shot. Let the facts determine which profile is selected:

- A factual human story usually fits 01 or 05.
- An immediate danger story usually fits 02.
- A direct demonstration or “how it works” idea usually fits 04.
- A joke or absurd everyday event usually fits 03.

Before expanding the reference set, choose the primary mode and collect more examples that match it. Five mixed examples can establish a toolbox, but they are too few and too varied to define one locked visual identity.
